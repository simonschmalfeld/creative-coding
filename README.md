# creative-coding

A collection of creative coding experiments, mostly built with [p5.js](https://p5js.org/).

## Sketches

- **blobs** — organic blob shapes drifting and morphing on canvas
- **facemesh** — webcam face tracking (ml5.js) that attracts particles to facial landmarks
- **flower** — image-based flower generative art with pixel displacement
- **neon-kanji** — random Japanese kanji rendered in a neon Tokyo / manga aesthetic
- **particles** — particle system with connecting edges, pulses, and clusters
- **rectangles** — generative rectangle patch compositions
- **startrails** — simulated long-exposure star trail arcs
- **sunset** — procedural gradient sunset scenes
- **tropical-diffusion** — interactive procedural tropical flowers with optional AI-enhanced (Stable Diffusion) textures

## Usage

Most sketches are static and can be opened directly by loading `index.html` in a browser. `tropical-diffusion` is a small Node app — see its own README for setup.
